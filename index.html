Trabalhos

Distri Rio

Site e catálogo, no ar em distririo.com.br

Site e catálogo de uma distribuidora de doces, bebidas, energéticos e suplementos que atende comércios do Rio de Janeiro e da Baixada Fluminense. O comerciante monta a lista de pedido no catálogo, e ela chega pronta no WhatsApp da distribuidora.

Por dentro

  • O catálogo inteiro fica num único arquivo JSON. Um script em Node gera, a partir dele, as 333 páginas de produto e as 19 de marca.
  • A cada push, o GitHub Actions confere os links, as imagens e os fluxos principais num Chrome sem interface.
  • Não tem framework: é HTML, CSS e JavaScript puros, publicados no GitHub Pages com domínio próprio.
  • Imagens em WebP e AVIF, dados estruturados para o Google e cookies de medição só depois do aceite, como pede a LGPD.

Catálogo de Séries

Projeto de estudo na Alura

Um catálogo que carrega as séries de um arquivo JSON, com busca por nome, filtro por gênero e os detalhes de cada título numa janela. Fiz para praticar front-end: mexer no DOM, trabalhar com dados em JSON e montar um layout responsivo.
